More on variables in Python: 
>>> num = 5
>>> num
5

-- To find the address of num we do: 
>>> id (num)
1772709024

--To find the address of the string:
>>> name = 'Anshul'
>>> id(name)
60625120

--If we create multiple variables and they have same data they both will have same address:
>>> a= 10
>>> b=a
>>> a
10
>>> b
10
>>> id(a)
1772709104
>>> id(b)
1772709104
>>> k=10
>>> id(k)
1772709104

--If we change the value of a: we get new address for a but address for b and k still remains the same
>>> a=9
>>> id(a)
1772709088

--when we make K =a.Then k also refers to the address of A 
>>> k=a
>>> id(k)
1772709088

--We cannot keep the constant value same for EG: PI = 3.14  
>>> PI = 3.14
>>> PI
3.14
>>> PI = 3.15
>>> PI
3.15

--To know the type for any particular variable we just say type(Variable_name)
>>> type (PI)
<class 'float'>
